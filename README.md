
# نظام إدارة مبيعات ومخزون الكتب (Bookstore CLI)

مشروع بسيط لتطبيق أساسيات لغة JavaScript (JS 101).

## المفاهيم المطبقة:
- المصفوفات ثنائية الأبعاد (2D Arrays)
- حلقة التكرار (for loops)
- الجمل الشرطية (if / else if / else)
- الدوال ونطاق المتغيرات (Functions & Scope)

## مميزات البرنامج:
- البحث عن كتاب بالاسم.
- التحقق من توفر الكمية بالمخزن قبل الشراء.
- التحقق من كفاية رصيد العميل.
- خصم الكمية المباعة تلقائياً وإصدار فاتورة شراء.
